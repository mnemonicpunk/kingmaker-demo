Build directions (not needed to run this demo):
1. Download/extract the exact source archive, or clone and checkout the full commit above.
2. Install the upstream-pinned Emscripten 6.0.9 toolchain, Node/npm and make.
3. Download/verify the exact network above into src/.
4. The upstream tag has no npm lockfile. In its root run npm install --ignore-scripts
   (the source package pins terser =5.51.2; upstream transitive build dependencies are not locked), then:
   node build.js --single-threaded --lite --no-split --strict-em-check -f
   (npm run build-single-lite is the upstream convenient equivalent.)
5. Outputs are written under src/. Upstream scripts/prepack.js documents npm packaging.
See the pinned README.md, build.js --help, Makefile and wasm-makefile.mk for platform prerequisites.
